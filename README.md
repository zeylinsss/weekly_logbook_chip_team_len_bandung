# Weekly Logbook Design Chip Team LEN Bandung

Weekly logbooks of each Design Chip Team LEN Bandung member, kept as one Markdown file per member. It lets the team and mentors track activities, results, and blockers every week.

## Structure

```text
weekly_logbook_chip_team_len_bandung/
├── README.md
├── DD_MM_YY/        # one folder per week, added weekly
│   ├── <member_1>.md
│   └── <member_n>.md
└── DD_MM_YY/
```

## Adding a Logbook

1. Create a new `DD_MM_YY` folder for the week (or use the existing one).
2. Add your own `<member_name>.md` inside it.
3. Cover the period, summary, daily activities, learnings, and blockers.
4. Commit and push without editing other members' files.
